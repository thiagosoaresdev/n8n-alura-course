## 🤖 O que é n8n?

[n8n](https://n8n.io/) é uma plataforma de automação de workflows de código aberto que permite conectar diferentes serviços e APIs de forma visual, criando integrações poderosas sem necessidade de código complexo.

### Principais características:
- Interface visual para criação de workflows
- Mais de 200 integrações nativas
- Código aberto e auto-hospedável
- Suporte a scripts customizados
- Execução em tempo real ou agendada

## 🚀 Como Usar

1. Instale o n8n:
   ```bash
   npm install n8n -g
   ```

2. Inicie o n8n:
   ```bash
   n8n start
   ```

3. Acesse a interface web em `http://localhost:5678`

4. Importe os workflows disponíveis neste repositório
